# 0.1 — Toegankelijkheid (axe-core) nulmeting

Bron: `scripts/baseline/cwv-axe.mjs --only=axe` (2026-10-06), ruwe data in
`raw/axe.json`, tabel in `raw/tables-axe.md`.

## Opzet

- **Engine:** axe-core 4.12.1 (versie vastgelegd in de lockfile), geïnjecteerd in lokale Chrome
  154 via het DevTools-protocol. Geen `@axe-core/cli`: die haalt bij installatie
  chromedriver@latest op (fragiel en extra download).
- **Regelset:** tags `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`.
- **Pagina's:** `/`, `/boeken`, `/tarieven`, `/taxi-almere-schiphol` op `https://www.t4xi.nl`
  (NL zonder prefix; het kale domein redirect met 308 naar www).
- **Viewports:** mobiel 412×823 @1.75 met moto-g-UA (gelijk aan Lighthouse mobiel),
  desktop 1350×940.

## Resultaat: violations

| Pagina | Mobiel | Desktop |
|---|---|---|
| `/` | 0 | 0 |
| `/boeken` | `color-contrast` (serious), 3 nodes | idem |
| `/tarieven` | `color-contrast` (serious), 1 node | idem |

Elke pagina heeft precies één `h1` en `lang="nl"`.

### `/boeken`: labels van de stad/stadsdeel-pills

- Selector: `.rounded-xl.bg-fog.py-2\.5:nth-child(1..3) > small`
- Bron: `components/booking/BookingSection.tsx:552`
  (`text-[10px] uppercase ... text-stone` op `bg-fog`).
- Gemeten: #999694 op #F5F3F1 = **2,65:1**, 10px normaal gewicht. Minimaal vereist: 4,5:1
  (WCAG 1.4.3).

### `/tarieven`: tweede regel van de hero-kop

- Selector: `.font-light` (de `heroKop2`-span in de `h1`)
- Bron: `app/[locale]/tarieven/page.tsx:115` (`font-light italic text-stone`).
- Gemeten: **2,65:1** bij 38px (mobiel) / 83,7px (desktop). Ook voor grote tekst minimaal 3:1.

### Grondoorzaak

Het token `stone.DEFAULT` (#999694, `tailwind.config.ts:30`, omschreven als "platinum accent")
wordt als tekstkleur gebruikt: `text-stone` komt 138 keer voor in 40 bestanden onder `app/` en
`components/`. Op de lichte achtergronden (`fog`, wit) haalt het nergens 3:1. axe meldt alleen
de gevallen die het zeker kan berekenen; de rest staat onder *incomplete* (zie hieronder).
Het bestaande token `stone.text` (#5F666D, ongeveer 5,3:1 op #F5F3F1) voldoet wel. Dit is een
mogelijke richting, nog geen ontwerpbesluit.

*Incomplete* betekent dat axe het niet kan beslissen (vaak tekst op een afbeelding, verloop of
semi-transparante laag). Dit zijn geen bevestigde fouten, maar gezien de grondoorzaak hierboven
is de verwachting dat een deel ervan echt onder de norm zit.

## Beperkingen

- Een geautomatiseerde scan dekt grofweg een derde van de WCAG-criteria. Toetsenbordbediening,
  focusvolgorde, schermlezeraankondigingen en foutmeldingen in de boekflow zijn niet getoetst.
- Gemeten in de beginstaat van elke pagina; geopende dropdowns, de stappen van de boekflow en
  foutstaten zijn niet gescand.

## Findings

1. **Serious: `/boeken`, labels van de stad/stadsdeel-pills**: 2,65:1, minimaal 4,5:1
   (`components/booking/BookingSection.tsx:552`).
2. **Serious: `/tarieven`, hero-kop `heroKop2`**: 2,65:1, minimaal 3:1
   (`app/[locale]/tarieven/page.tsx:115`).
3. **Grondoorzaak: het token `stone` is als tekstkleur te licht** (138× `text-stone`). Een fix op
   tokenniveau ligt meer voor de hand dan losse patches; de 46–62 *incomplete* meldingen per
   pagina daarna opnieuw beoordelen.
4. **Prestaties (CWV):** volgt in `0.1-cwv.md` na de Lighthouse-run. Velddata (PSI/CrUX) is
   niet opgehaald: anoniem PSI-quotum HTTP 429, CrUX zonder key 403. Of er velddata bestaat is
   daarmee onbekend, niet "afwezig".
